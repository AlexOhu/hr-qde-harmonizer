# Triage labels

| Kanonische Rolle | GitHub-Label | Bedeutung |
|---|---|---|
| `needs-triage` | `needs-triage` | Issue muss bewertet werden |
| `needs-info` | `needs-info` | Weitere Angaben der meldenden Person fehlen |
| `ready-for-agent` | `ready-for-agent` | Spezifiziert und für einen Agenten bereit |
| `ready-for-human` | `ready-for-human` | Benötigt menschliche Umsetzung |
| `wontfix` | `wontfix` | Wird nicht umgesetzt |

Wenn ein Skill eine kanonische Rolle nennt, das entsprechende GitHub-Label
verwenden. Die Labels entsprechen direkt den Rollennamen.
